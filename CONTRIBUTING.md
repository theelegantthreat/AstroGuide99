# Contributing to AstroGuide99

Thank you for your interest in contributing to AstroGuide99! We appreciate your effort to help improve this project. This document provides guidelines and instructions for contributing.

## Code of Conduct

Please review and adhere to our [Code of Conduct](CODE_OF_CONDUCT.md) in all interactions within this project community.

## How to Contribute

### Reporting Bugs

If you find a bug, please open an issue with:
- A clear and descriptive title
- A detailed description of the problem
- Steps to reproduce the issue
- Expected behavior
- Actual behavior
- Any relevant logs or screenshots

### Suggesting Enhancements

We welcome feature suggestions! Please open an issue and include:
- A clear and descriptive title
- A detailed description of the enhancement
- Use cases and examples
- Why this enhancement would be useful

### Pull Requests

1. **Fork the repository** and create a new branch for your work
   ```bash
   git checkout -b feature/your-feature-name
   ```

2. **Make your changes** following the project's code style and standards

3. **Test your changes** thoroughly to ensure they work as expected

4. **Commit your changes** with clear and descriptive commit messages
   ```bash
   git commit -m "Add feature: brief description"
   ```

5. **Push to your fork**
   ```bash
   git push origin feature/your-feature-name
   ```

6. **Open a Pull Request** with:
   - A clear title and description
   - Reference to any related issues
   - A summary of changes made

## Development Setup

To set up your development environment:

1. Clone the repository
2. Install any required dependencies
3. Follow the project-specific setup instructions (if available in README)

## Coding Standards

- Follow the existing code style in the project
- Write clear and meaningful variable and function names
- Add comments for complex logic
- Ensure your code is well-tested

## Commit Messages

Use clear and descriptive commit messages:
- Start with a verb (Add, Fix, Update, Refactor, etc.)
- Be concise but informative
- Reference issues when applicable (e.g., "Fixes #123")

## Review Process

All contributions go through a review process:
- Maintainers will review your PR for code quality, style, and functionality
- Be open to feedback and discussion
- Make requested changes promptly

## Questions?

If you have questions about contributing, feel free to:
- Open a discussion or issue
- Reach out to the maintainers

Thank you for contributing to AstroGuide99!
